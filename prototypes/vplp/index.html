Frequently Asked Questions

Will these roof racks fit my Hilux if it's a different generation to N80?

No — every product on this page is matched exactly to the Toyota Hilux N80 (2015–2026), 4dr Ute, Bare Roof shown above. A different generation, body style or roof type needs its own exact-fitment kit; set your vehicle again if any of those details are different.

What's the difference between a platform and a cross bar set?

Cross bars are a simple pair of load bars for general use — bike racks, roof boxes, cargo. Platforms add a full tray surface, better suited to loose or bulky gear, awnings and touring setups. Use the Platform Style priority filter to narrow by which you need.

My Hilux has a styling bar, not a bare roof — do these still fit?

No — roof type changes the mounting system entirely. This page is scoped to Bare Roof only; use "Change Vehicle" above and re-select your roof type to see the correct styling-bar-compatible range.

Can I get any of these professionally fitted, and does it cost extra?

Yes — every kit here can be booked for fitting in-store. Fitting charges apply and are confirmed before installation; see the Gold Guarantee tab on the product page for what's covered.
