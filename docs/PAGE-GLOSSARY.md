# PDP Page Glossary

*Updated for the 2026-09-29 cross-template consistency pass (`spec.md` §15). Entries changed by that pass say so; new shared building blocks it introduced are in "Shared building blocks" near the end.*

Reference for naming the parts of the product page (PDP) templates, so "gallery," "widget," "panel," etc. all mean one specific thing in conversation. Split into **Sections** (structural blocks that lay out the page) and **Widgets** (interactive components that live inside sections). Where a name has caused confusion before, that's called out explicitly.

Applies across the 5 PDP templates in `prototypes/`: **Simple**, **Sibling-Color**, **Config-Variant**, **Vehicle-Specific**, **Grouped-Bundle**. The **Vehicle Category Landing Page** (`prototypes/vehicle-category-landing/`, added 2026-09-15) is a different page type — one page per make/model rather than per product — and gets its own short section near the end of this file rather than being folded into the tables below, which are PDP-specific. The listing pages (PLP, PLP Camping, VPLP, Search Results) are named in their own briefs (`PLP-DEVELOPER-BRIEF.md`, `SEARCH-RESULTS-DEVELOPER-BRIEF.md`); this file only covers the pieces they share with the PDPs/VCLP, plus the two prototype panels.

## ⚠️ Naming clash to know about: "Gallery"

There are **three different things** that have all been called "gallery" at some point. Use the specific name:

| Specific name | What it is | Where it lives |
|---|---|---|
| **Main Product Gallery** | The primary product photos — big image + thumbnail strip at the top of the page, beside the Decision Panel. Always stays put beside the Decision Panel; nothing moves it. | `.gallery-main`, `.gallery-thumbs`, `.gallery-col` — all templates |
| **Fitted Photos Gallery** | Real customer installation photos, presented as the "Gallery" panel widget (icon badge, "View All In-store Fitments (N)" link, "Explore Fitting Costs" button, photo carousel with nav arrows + page dots) — separate from the Main Product Gallery entirely. Final design locked in 2026-09-12: full width above the Trust Row, non-red background, permanently (the placement/red-background Demo State Panel toggles that previously existed to help decide this have been removed). | `.fit-gallery-section` / `.fit-gallery-panel` — **Vehicle-Specific (the only PDP), VCLP and VPLP**, all built by one shared builder since 2026-09-29 |

When you say "the gallery" going forward, say which of the three you mean, or use the bold name above.

## Sections

Top-to-bottom structural blocks. Not every section appears on every template — noted where limited.

| Section name | Description |
|---|---|
| **Utility Bar** | Thin top strip above the main header (nearest store, vehicle, call us, region, account) — `.rrg-utility-bar` |
| **Region Selector** | The Utility Bar's "🇦🇺 Australia ▾" item — previously decorative-only, now a working dropdown (2026-09-11, backlog item 21). A live client-side region swap (AU/NZ/UK), no page reload, resets to AU on every page load (unlike the Demo State Panel, whose choices persist per template since 2026-09-29). Desktop only (same as the rest of the Utility Bar's right-hand items). See Widgets below for what it cascades into. — `.region-switcher` / `applyRegion()` |
| **Main Header** | Logo, nav links, search bar, cart icon — `.rrg-main-header` |
| **Breadcrumbs** | Trail above the hero — `.rrg-crumbs`. 3 levels (Home → Category → Product) on Simple/Config-variant/Sibling-color/Grouped-bundle. Vehicle-Specific follows the one **vehicle breadcrumb family** agreed 2026-09-29 (`spec.md` §15 L8, provisional pending team review): VCLP `Home › Vehicles › Toyota › Hilux`, VLP `… › Hilux › 2015–2026 › 4dr Ute › Bare Roof` (2026-09-29), VPLP `… › Bare Roof › Roof Racks` (a child of the VLP since 2026-09-29), VS `Home › Vehicles › Toyota › Hilux › Platforms & Trays › <product name>` (was "Home → Toyota Hilux N80 → …"). Note: this class name doesn't contain the word "breadcrumb" — a session grepped for that literal word 2026-09-10 and wrongly concluded breadcrumbs didn't exist. Search for `.rrg-crumbs` instead. |
| **Hero** | The main above-the-fold row: Main Product Gallery on the left, Decision Panel on the right — `section.hero` |
| **Decision Panel** | The right-hand sidebar column in the Hero: brand logo, SKU, price, fitment status, variant/colour picker, Add to Cart, payment badges, Delivery/Click & Collect widget — `.decision-panel`. **Mobile only (≤900px, 2026-09-10):** renders above the video/Get It Installed row, not below it — `.gallery-col`'s children become independent `.hero` grid items via `display:contents` so gallery images/thumbs, Decision Panel, and the video/install row can each be ordered independently without moving any markup. |

| **Fitted Photos Gallery section** | "See it fitted to a [vehicle] just like yours" — grid of real installation photos. **Vehicle-Specific only among the PDPs** (also on VCLP and VPLP). See naming clash above. |
| **Short Description** | The real Rackit short-description field, under the title in the Decision Panel, on all 5 templates — see the "Short description 'Read more'" widget entry below (consolidated here 2026-09-11; this row previously described the pre-consolidation layout). |
| **Body Tabs section** | Full-width area containing the Tabs widget (Details/Specifications/Gold Guarantee/Shipping/Fitting Instructions) — `.body-cols` |
| **Related Products section** | "Related Products" heading + grid of cross-sell product cards — `.related-heading` / `.related-grid` |
| **Design Rationale section** | Bottom-of-page internal/reviewer section explaining build decisions and trade-offs — not part of the shipped design — `.rationale` |
| **Sticky Mobile Bar** | Condensed product name + price + Add to Cart bar fixed to the bottom of the screen, mobile only — `.sticky-cta-mobile`. **Name + price + CTA on all 5 templates** (2026-09-29, `spec.md` §15 D4 — Vehicle-Specific previously showed no price), with one shared price markup: `.sticky-price` holding `.price-now` + `.price-was` (no inline styles). | **Persistent Bar** | Condensed fitment/price + Add to Cart bar fixed to the top of the screen on desktop, fades in once the Decision Panel scrolls out of view — `.persistent-bar`. Its price mirrors the main price block, including the Demo "on sale" toggle (was left stale before 2026-09-29). |

## Shared building blocks (2026-09-29 consistency pass)

Site-wide pieces that the consistency pass (`spec.md` §15) turned into one shared rule each. Use these names rather than the old per-page ones.

| Name | Description |
|---|---|
| **Category hero** | The hero shared by the PLP family (PLP, Camping, VPLP) and the VCLP — H1 + description on the left, photo (vehicle or category image) with an optional round make badge on the right. Text is top-aligned so the H1 never moves between Shop By tabs; desktop photo box is a fixed 250px tall; on phones the photo sits above the text, and on the PLP family the description clamps to 3 lines with "Read more". Lives in shared.css (VCLP's drifted `.vclp-hero` copy is gone). — `.plp-hero` / `.plp-hero-media` / `.plp-hero-make-badge` / `.plp-hero-readmore` |
| **Breadcrumb row** | Breadcrumb trail + **Change Vehicle** button on one line, above the Category hero on the PLP family and VCLP. Always one line — the trail truncates with an ellipsis. Change Vehicle is the one site-wide style: red outline, compact size (`.btn-outline-red`, `.btn-sm` sizing), and opens the Fit Finder drawer. Search's "Change vehicle" uses the same button. — `.plp-crumbs-row` / `.plp-crumbs-cta` |
| **Buttons** | One button system in shared.css. Sizes: `.btn` (16px) · `.btn-lg` · `.btn-md` (14px) · `.btn-sm` (13px, 12px on phones). Colours: `.btn-primary` (red) · `.btn-cta` (gold — every Add to Cart and primary purchase/vehicle action, **green in the UK region**; replaces `.btn-gold` and the gold-recoloured `.btn-primary`) · `.btn-outline` (black, with a hover) · `.btn-outline-red` (secondary vehicle actions — Change Vehicle, fitment-card actions). No inline button styles. |
| **Page H1 / section H2** | One page H1 rule — 32px / 1.1, 28px on phones (PDP, PLP family, VCLP, Search). Section headings (Related Products, Showroom Finder, Fitment Gallery, FAQ, Tabs, Fit Finder, content blocks, Trust banner) share one 40px Barlow Condensed italic uppercase rule, stepping down to 32px on phones. |
| **Eyebrow label** | The small grey uppercase label above a group — "Build Option", "Colour", "What's Included", "Consists Of", "Featured Product", the typeahead and region-menu section heads. One rule (was four near-identical versions). — `.eyebrow` (and the existing classes grouped onto the same rule) |
| **Text-link button** | One style for link-looking buttons (underlined, red, 14px bold): "Clear Filters", "View All In-store Fitments", specs toggles, etc. (was 6 variants). — `.link-btn` |
| **Chip** | One small uppercase status-label style (11px, 900 weight, 6px radius), colour per modifier — store stock pills, Ex-Demo option tags, variant-card "Save N%" badge (now red, was green). — `.chip` (grouped with `.stock-chip`, `.eo-tag`, `.v-badge`) |
| **Drawers** | Every right-edge slide-out (Store, Ex-Demo/B-Stock, Fitment Gallery, Fit Finder, and the PLP filter/compare drawers) shares one base: 420px standard width, 600px for the Fitment Gallery and Compare (`--drawer-w`), 22px titles, the 48px round grey close button, `role="dialog"`, and one Escape-to-close handler; also closes on a backdrop click. |
| **Tooltip** | One tooltip bubble style (charcoal, 14px) for the filter and fitment tooltips. — `.rrg-tooltip` |
| **Carousel dots and arrows** | Round grey 8px dots with a red active dot, shared by the Fitment Gallery and the PLP sidebar merch banner (was black pills vs red circles); carousel arrows are 32px. — `.fit-gallery-dot` / `.plp-merch-dot` |
| **Selects** | One select style (Fit Finder selects and the PLP Sort select): same chevron and padding; inputs and selects are 16px on phones so iOS doesn't zoom. The compare checkbox is red like the filter checkboxes. |
| **Featured Product** | The listing-page sidebar merch card, rebuilt from the shared card price markup (RRP, sale colour and Save band like every other card). — `.plp-featured-product` |
| **Section spacing and tokens** | Every major section uses one 48px rhythm (`--space-section`) with 16px from heading to content, and a 48px gap above the footer on every page (VCLP's grey brands band is flush instead). Colours, greys, shadows and motion come from `shared.css :root` tokens (e.g. `--rrg-cta`, `--rrg-uk-green`, `--rrg-charcoal`, `--rrg-grey-500/600/700`) rather than hardcoded values. |
| **Global shell** | Every page — including the template index (`prototypes/index.html`, which now uses the real header, mobile takeover and footer instead of a hand-copied header) and the standalone header prototype (`header/index.html`, which now loads shared.js; `header/header-standalone.js` is deleted) — loads the same header, footer and script set. Titles follow "Page name — Roof Racks Galore"; every page has `lang="en-AU"` and the real favicon; the mobile-takeover logo links to the template index. |
